# اسلایدر تصویر (Image Slider)

یه پروژه‌ی تمرینی برای یادگیری مدیریت State و Event Handling در جاوااسکریپت خالص — بدون هیچ کتابخونه یا فریم‌ورکی.



## این پروژه شامل چیه؟

یه اسلایدر تصویر کامل با سه روش ناوبری:

- **دکمه‌های بعدی/قبلی** — جابه‌جایی بین تصاویر با چرخش دایره‌ای (بعد از آخرین تصویر، به اولی برمی‌گرده)
- **حرکت خودکار** — تعویض خودکار تصاویر با فاصله‌ی زمانی مشخص، با ریست‌شدن تایمر هنگام تعامل دستی کاربر
- **ناوبری نقطه‌ای (Dots)** — کلیک مستقیم روی هر نقطه برای رفتن به تصویر مربوطه، با هایلایت شدن نقطه‌ی متناظر با تصویر جاری

## مفاهیمی که تمرین شده

- مدیریت **State** با متغیر (`currentIndex`) به‌جای تکیه بر DOM
- متدهای `classList.add()` و `classList.remove()`
- `setInterval` و `clearInterval` برای کنترل حرکت خودکار
- پیمایش لیست عناصر با حلقه‌ی `for` و اتصال Event Listener به هرکدوم
- استفاده از `data-*` attribute (`data-index`) برای ارتباط بین DOM و منطق برنامه
- متغیرهای CSS (`:root`) برای تم‌بندی و جلوگیری از تکرار مقادیر
- ترنزیشن نرم با `opacity` به‌جای `display: none/block`
- ریفکتور کد (ادغام دو تابع مشابه در یک تابع پارامتری، برای رعایت اصل تابع تک‌مسئولیتی)

## تکنولوژی‌های استفاده‌شده

- HTML5
- CSS3
- JS

## استفاده از هوش مصنوعی

در این پروژه، از هوش مصنوعی (AI) به‌عنوان یک **منتور و ابزار کمکی برای یادگیری**، نه نویسنده‌ی کد، استفاده شده است. روند کار به این شکل بود که برای هر بخش (مدیریت State، ناوبری، حرکت خودکار، دات‌ها) AI فقط مفهوم رو توضیح می‌داد و قدم‌به‌قدم راهنمایی می‌کرد، و خودِ کد رو من می‌نوشتم.

از AI برای موارد زیر استفاده کردم:
- توضیح مفاهیم جاوااسکریپت (مثل State، Event Listener، `setInterval`) پیش از نوشتن کد
- بررسی و Debug کردن کد (مثلاً پیدا کردن دلیل عدم آپدیت رنگ دات‌ها که نهایتاً مشکل کنتراست رنگ بود، نه منطق کد)
- بازخورد درباره‌ی ساختار و تمیزی کد (مثل جداسازی منطق تکراری در یک تابع مشترک)

## Lessons Learned

مهم‌ترین نکته‌ای که از این تمرین یاد گرفتم، اهمیت **جدا کردن منطق تکراری** بود؛ در نسخه‌ی اولیه، توابع ناوبری «بعدی» و «قبلی» تقریباً کدهای یکسانی داشتند که در نهایت در یک تابع مشترک با پارامتر جهت (`direction`) ادغام شدند.
