# اسلایدر تصویر — Image Slider


یک اسلایدر تصویر ساده و کامل، نوشته‌شده با **HTML، CSS و JavaScript خام** (بدون هیچ کتابخانه یا فریم‌ورکی)، با قابلیت ناوبری دستی، حرکت خودکار، و ناوبری نقطه‌ای (Dots).

---

## ✨ امکانات

- نمایش تصاویر به‌صورت یکی‌یکی با ترنزیشن نرم (fade)
- دکمه‌های «بعدی» و «قبلی» با چرخش دایره‌ای (بعد از آخرین تصویر، به اولی برمی‌گردد)
- حرکت خودکار اسلایدها هر ۲ ثانیه (`setInterval`)
- ریست شدن تایمر خودکار هنگام تعامل دستی کاربر
- ناوبری نقطه‌ای (Dots) پایین تصویر؛ کلیک روی هر نقطه مستقیم به همان تصویر می‌رود و نقطه‌ی مربوط به تصویر جاری هایلایت می‌شود
- طراحی واکنش‌گرا با متغیرهای CSS (`:root`) برای رنگ‌بندی و اندازه‌ها

---

## 🛠️ تکنولوژی‌ها

- HTML5
- CSS3 (Custom Properties / Variables)
- JavaScript (Vanilla — بدون jQuery یا کتابخانه‌ی دیگر)
- [Font Awesome](https://fontawesome.com/) برای آیکون‌ها

## 🤖 استفاده از هوش مصنوعی در این پروژه

در طول این تمرین از **Claude** (دستیار هوش مصنوعی) به‌عنوان یک **راهنما و منتور**، نه نویسنده‌ی کد، استفاده شده است. روند کار به این شکل بود:

- هوش مصنوعی **هیچ‌جای کد را مستقیم ننوشت** (به‌جز چند خط کاملاً تزئینی/غیرمنطقی مثل مقادیر اولیه‌ی `:root` و افکت‌های ظاهری CSS که خودم درخواست دادم نوشته بشه)
- برای هر بخش (مثلاً منطق ناوبری، مدیریت State، حرکت خودکار)، هوش مصنوعی فقط **مفهوم را توضیح می‌داد و قدم‌به‌قدم راهنمایی می‌کرد**، و خود کد را من می‌نوشتم
- وقتی کد اشتباه داشت (مثل سینتکس غلط `var()`، ترتیب اشتباه آرگومان در `setInterval`، یا حلقه‌ی بی‌نهایت در `updateDots`)، هوش مصنوعی اشکال را مشخص می‌کرد و دلیلش را توضیح می‌داد، ولی اصلاح را خودم انجام می‌دادم
- برای دیباگ مشکل «دات‌های ناوبری که رنگشان تغییر نمی‌کرد»، با راهنمایی هوش مصنوعی به این نتیجه رسیدیم که مشکل از کنتراست رنگ بوده، نه منطق کد
- پیام‌های Commit (فارسی و سپس ترجمه‌ی انگلیسی) هم با کمک هوش مصنوعی نوشته شد
- در پایان، برای یادگیری مفهوم تابع پارامتری، با راهنمایی هوش مصنوعی توابع `showNext`/`showBack` در یک تابع مشترک `changeSlide(direction)` ادغام شدند (ریفکتور)

**جمع‌بندی:** هوش مصنوعی نقش منتور و مسئول بررسی کد (Code Review) را داشت؛ نوشتن، تایپ کردن، و رفع اشکال نهایی همیشه بر عهده‌ی خودم بود.
